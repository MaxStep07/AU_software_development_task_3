## ⚙️ Требования

- **Linux** или **Windows Subsystem for Linux (WSL)** с установленным дистрибутивом Linux, например Ubuntu.
- **Bash**.
- Стандартные командные утилиты Linux: `awk`, `grep`, `sed`, `ls`, `df`, `date`, `tr`, `wc` и другие.

Дополнительные библиотеки Python или сторонние пакеты для представленных скриптов не требуются.

Проверить наличие Bash и его версию можно командой:

```bash
bash --version
```

## 🚀 Установка и запуск

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/MaxStep07/AU_software_development_task_3.git
   cd AU_software_development_task_3
   ```

2. Перейдите в каталог нужного задания. Например, для заданий из `task_3_8`:

   ```bash
   cd projects_3/task_3_8
   ```

3. Запустите нужный скрипт с помощью Bash:

   ```bash
   bash hello.sh
   ```

   Аналогично запускаются остальные скрипты — вместо `hello.sh` укажите имя нужного файла.

При необходимости скрипт можно сделать исполняемым и запускать напрямую:

```bash
chmod +x hello.sh
./hello.sh
```

Для корректной работы скриптов, использующих входные файлы по относительным путям, запускайте их из соответствующего каталога задания.

## ⚠️ Особенности отдельных заданий

- **`task_3_9/log.sh`** проверяет наличие файла `system.log` в текущем каталоге. Такого файла в репозитории нет, поэтому без его создания скрипт сообщит, что файл не найден.
- **`task_3_10/nucleotides_count.sh`** обращается к каталогу `nucleotides_files` относительно текущей рабочей директории. Запускайте его из `projects_3/task_3_10`:

  ```bash
  cd projects_3/task_3_10
  bash nucleotides_count.sh
  ```

- **`task_3_11/check_root.sh`** проверяет, запущен ли скрипт с правами суперпользователя. Для демонстрации этой проверки его можно запустить командой `sudo bash check_root.sh`.
- **Скрипты в `task_3_13`** используют `sed -i` и изменяют файлы `settings.php` и `sequences.txt` непосредственно. Перед запуском сохраните исходные копии, если хотите оставить примеры данных без изменений.
- **`task_3_10/files_roundtrip.sh`** создаёт, а затем удаляет файлы `test1.txt`–`test10.txt` в текущем каталоге. Запускайте его из папки задания.

Для заданий, запрашивающих данные у пользователя или принимающих аргументы командной строки, следуйте подсказкам скрипта либо передавайте аргументы при запуске.
